## Decisions and questions that need you

- **Q1. Extent of the A1 half-spacing region** (DL-083 left it open). Options: (a) a band of fixed width in eta_bar around the formula fold curve (K1) over the whole J range; (b) a box around the cusp only, since the failure was at r = 0.279 and 0.324 (DL-078); (c) the band of (a) with a wider box at the cusp. The width in cells is also yours to give. Table 6.2's rule ("halving moves the boundary by less than one cell") was not met at the cusp (DL-081); say whether A1 should report that check and where.
- **Q2. K8/S3 start-state selector.** Build a config key for the start state now (MS2), or defer to MS5 when S3 is run? Default if you say nothing: defer to MS5 and say so in the gate report. Note that the stable-root rule (DL-053) raises an error when there is not exactly one stable root, which is the K8 situation only if the start point has more than one.
- **Q3. baseline_s wiring.** Reject a config where `path.t_on_s` is not `durations.baseline_s` or `path.J0` is not `model.J` (the first option in DL-077), or remove the dead keys from the hash? Default: reject.
- **Q4. New path kinds for S1.** The config has no step-I or sinusoidal-I path (only the ramp and trapezoid kinds, ramps.py and config.py). K4 and K5 need them. Adding two path kinds extends the config schema. Default: add `I_step` and `I_sin` kinds, with the values from replication.yaml and no other new default. Say if you would rather run S1 through a separate small driver.
- **Q5. G0 part 1 on failure.** Table 11.2 G0: still failing after two debugging rounds means stop new work and check the equations, C3 and the units. Confirm that applies as written, with no tolerance change (the tolerances are frozen).
- **Q6. FS1.** FS1 (K1 to K3, K4 and K5 traces, ring map) feeds G0, but the MS2 row lists only A1, A2 and S1. Default: no figure at MS2; FS1 waits for the figure milestone. Say if you want it in MS2.
- **Q7. Module for the A2 fit.** The handoff list (d) has no module for the ring fit. Default: put `fit_damped_sinusoid` and the linearisation helpers in `analysis/ring.py` (new file), and list it in the layout notes. Say if you want it in `surge_metrics.py` instead.
- **Q8. UNVERIFIED values used.** MS2 relies on UNVERIFIED items, all marked in replication.yaml: K4 tail fraction 0.1, K5 burst midpoint and 0.1 tau tolerance, the tau mapping. They are used as written, with no change.
