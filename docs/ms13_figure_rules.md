# MS13 figure rules (13t, J11; short numbered lines; later prompts point here)

Sources: G1 to G12 from DL-511 (and the code helpers in `plotting/captions.py` and `plotting/figures.py`); J1 to J15 from the 13t-1 prompt (DL-545); R1 to R10 from the 13t-1b prompt (DL-554), which supersede the conflicting parts of J4, J5, J9 and J14; STOP RULE 12 from the 13t-1 prompt. The plan (`docs/plan.md`) is not changed. Everything the plan does not state is UNVERIFIED. All eleven figures are untagged drafts; a tag is made only when the user says "tag".

## G1 to G12 (the draft figures, DL-511)
1. G1 class key: every figure that draws classes has one key line, verbatim from plan Table 2.1, saying which classes are surge classes (`captions.class_key_line`).
2. G2 failures visible: the word FAIL is in the title of every panel that shows a failed check; the red title colour is defined once per figure (`captions.RED_TITLE_NOTE`); FAIL lines are bold; no text below the tick-label size of the draft; blank strip values are explained from the A11 columns, else "blank in the stored table" (`figures.strip_line`).
3. G3 caption order: sentence 1 is the take-home and names the main failure(s) (`build_caption(main_failures=...)`); then what is drawn; then the claim-limit list.
4. G4 pinned values are labelled with their meaning when stored values or frozen code settle it, else "pinned value, cause not determined (UNVERIFIED)".
5. G5 parameters sentence: per-panel tags; swept parameters as range or list (`captions.sweep_text`); noise.sigma only where drawn records use noise, with "checked, not confirmed", G4-C4.
6. G6 class colours and class markers for classes only; seeds, levels and variants use the series marks and the network-seed lightness (`style.series_mark`, `style.network_seed_colour`).
7. G7 coincident stored values keep their stored positions and carry a "coincide" note naming the series (`captions.coincide_note`).
8. G8 classifier and spectrogram settings in one caption line, read from the frozen criteria (`captions.classifier_line`).
9. G9 plain labels: symbols for eta-bar, tau_d and Delta, units, "log axis", one number format (`captions.number_text`), internal codes defined once (`style.INTERNAL_CODES`), P2 = "hypoxia-like path".
10. G10 short on-panel claim-limit pointers only where they change how a panel reads (`figures.claim_pointer`); in the journal export they move to the caption.
11. G11 a number stated but not drawn is marked "(not drawn)" or removed (`captions.not_drawn`).
12. G12 the draft footers keep "as ruled (DL-...)" and cite DL-511 and DL-512 (13r) and DL-537 and DL-538 (13s); the journal export has no footer on the image.

## J1 to J15 (the journal export, DL-545)
1. J1 on the image: panel letters in reading order (top to bottom, left to right); axis labels with units and "log axis" where used, with symbols not code names; legends; class legend marks; short panel titles with FAIL in the title of every panel that shows a failed check (red title); short in-panel lines that change how a panel reads; network symbols; "coincide" notes that sit on a plot.
2. J2 moved out: DRAFT marks, "as ruled (DL-...)" footers, provenance text, status strips and blocks, G10 pointers, internal ID keys (defined once in the caption), long notes inside panels. They go to the caption or to the supplement sheet of the figure. No caption, figure number or title is drawn inside the figure file.
3. J3 failures stay visible (plan 7.2): every FAIL, NOT PASSED, NOT EVALUABLE or FAILED line of the draft strip appears in a panel title or in the journal caption; caption sentence 1 names the main failure(s); the full strip is in the supplement sheet. Nothing is dropped.
4. J4 journal-neutral settings, all UNVERIFIED, all in `configs/journal_export.yaml`: width at most 7.5 in (double column), 84 mm as a second setting, height at most 8.75 in, all text at least 8 pt at the final size, Arial or Helvetica if installed (else DejaVu Sans, said so), vector text and lines, fonts embedded (pdf.fonttype 42, ps.fonttype 42, no Type 3), line width at least 0.3 pt, RGB, PNG 300 dpi, TIFF 600 dpi (LZW, flattened, no alpha) and EPS only if they build without error. No journal requirement is claimed. [Superseded in part by R1 (DL-554): width 6.3 in, height 8.0 in, PNG and TIFF 600 dpi main, PDF extra, file names `<ID>_journal.png`, `.tiff`, `.pdf`.]

Outputs: `figures/journal/<ID>/` (`<ID>_journal.pdf`, `.png`, `_caption.txt`, `_provenance.json`) and `figures/journal/supplement/` (`<ID>_supplement.md`, `<ID>_source_data.csv`, `<ID>_alt_text.txt`). `scripts/fig_journal.py <ID>` writes them and reads only results/. 8. J8 no collisions: nothing overlaps or touches (text-text, text-marker, text-line, text-image, text-frame, text-figure edge, legend-data, clipped text, marker-marker) unless it is in the allow-list with a reason; checked by code (`plotting/collide.py`) and by eye.

## R1 to R10 (13t-1b, DL-554; R1 supersedes the conflicting parts of J4, J5, J9 and J14)
R1. Venue: Peer Community Journal (PCJ), after a Peer Community In recommendation. PCJ prefers jpg, tiff or png figures, forbids svg, wmf and emf, states no resolution, size or colour rule, and places figures in line with the text inside 2.54 cm margins (read by the user; not re-read here). MAIN files of each figure: a PNG at 600 dpi and a flattened TIFF (LZW, no alpha) at 600 dpi (UNVERIFIED defaults); the vector PDF is an extra (300 dpi for rasterized parts); never write SVG, WMF or EMF; EPS only as an extra if it builds without error. MAIN width 6.3 in (UNVERIFIED: the PCJ template and page size were not read; A4 minus two 2.54 cm margins is 15.9 cm = 6.26 in), maximum height 8.0 in so that a caption fits on the page (UNVERIFIED); a second setting up to 7.5 in stays for other journals. Text at least 8 pt at the final physical size, fonts embedded, no Type 3. File names: `<ID>_journal.png` and `<ID>_journal.tiff` (main), `<ID>_journal.pdf` (extra). A PDF above 5 MB and a PNG or TIFF above 10 MB are flagged. The checks run on the main PNG and TIFF and on the PDF text boxes with the config values.
R2. Colour-vision simulation is NOT done in code (no package installed, none to be installed); the greyscale L* check and the non-colour-attribute check stay; the verifier row "cvd" reads "MANUAL (user checks final PNGs with an online simulator; UNVERIFIED)" and does not make the verifier exit non-zero. The hand-written matrices in `style.py` are not used.
R3. Allow-list approved: F3 (a)/(b) Hopf mark against the 25 Hz bar (stored positions); F3 (c) the A6 headline Hopf point is the Hopf point of the 5 ms slice (one stored point drawn twice; the caption says so); F1 (d) and (f) the three raw first-crossing marks overlap at the figure scale (wording: R6).
R4. FAIL placement: F5 (a) shows the RB1 cells result and F5 (g) draws network f_pk, so both titles carry FAIL (red title). The RB2 1.0_sigma FAIL is drawn in no F5 panel and stays in the caption and the supplement (J3). The F1 status-strip membership is not changed. One F1 caption sentence is added (values from the stored A11 table; a value that is not stored is left out).
R5. Accepted: tau_d written with an underscore; F1 and F5 use their own layout code in `figures.py` (DL-547 (2)), equality of the drawn-data digest to the draft is the control; the two shared manifest rows (figures.py, style.py) are rewritten as in DL-541 and DL-551.
R6. Wording of "coincide": used only where stored values are equal. The stored raw first crossings of F1 (50.170, 50.924, 50.857 s; span 0.754 s) are not equal, so in the journal text, alt text and caption they "overlap at this scale: stored values 50.170 to 50.924 s"; the three classifier onsets (12.000 s) are equal and "coincide". The draft label is left unchanged (close item 40).
R7. F1 (g) and (h): the thin white bands at the left and right edges are stated in the caption from the stored window length, step and time vector; if the stored times do not settle it: "blank in the stored record; cause not determined (UNVERIFIED)".
R8. F5 (c) and (d): the in-cell glyphs (bracket, x, plus) are unreadable at the cell size; they are replaced by a mark or hatch distinguishable at the cell size that appears in the key exactly as plotted (the non-colour check keeps passing); two attempts at most, then stop that item.
R9. If a safety check blocks a command, report it; do not reword the command to get past it.
R10. The source-data CSV of F1 (28 MB) is kept; the supplement notes that it is to be zipped for the Zenodo record.

## STOP RULE 12
On any pre-check mismatch, unopenable or changed file, a stored-input hash differing from the provenance, an independent value disagreeing with an original value, record or log text disagreeing with a stored value, a drawn-data digest of an export differing from its draft, a draft file changing, or a pre-existing test failing in the committed state: STOP, report both values and the reading, patch nothing.
