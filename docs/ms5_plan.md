# MS5 sub-step plan (planning only; no ruling yet, questions open)

MS5 plan, written before any MS5 code. Binding source: `docs/plan.md` (Table 11.1 row MS5; sections 5.2 A4, 6.2 S3 row of Table 6.2, 6.3, 6.4, 7.1 Table 7.1 K4 and K7 to K11 and Gate G0, 9.2, 9.3, Table 9.1, D12, D18, D34, D36, T04, T05, T23, CP21, CP26). Decisions go in `docs/decision_log.md`; this plan is DL-112 and holds none of its own. It changes nothing in the plan. Rules as for MS3 and MS4: one sub-step at a time; after each, `.venv\Scripts\python.exe -m pytest -m "not slow"` green, one commit `<type>(<scope>): <summary> [IDs]`, a report of at most 8 lines, then stop. No tags, no pushes unless asked. The `replication-pass` tag is not created by Claude: when the gate is ready, stop and ask. Every run writes a provenance record (6.6). Drivers only integrate, analysis modules only analyse, figure scripts only plot (10.1). Nothing is run in 5a.

**MS5 row (Table 11.1):** "M3 replication and network: A4, S3 (K7-K11), K4-net (once a source gives the M2 network coupling; section 12.4); network code and timing; sigma calibration run (N = 10^4 baseline); headline re-timed". Gate: "K7-K9 pass (K9 as in Table 7.1); K4-net passes, or is recorded as not run while the coupling is unsourced (non-blocking); sigma committed; tag replication-pass". Unlocks: "G0 complete; MS6". Depends on MS2 (K1 to K5 done), MS3 (timing machinery done) and MS4 (G1 ruled: move to M3, DL-111).

**Goal as the plan states it:** replicate the M3 results. A4 finds M3 fixed points and Hopf curves (Jacobian in tau-units, Hopf where a1 a2 = a3 with a1, a3 > 0, brentq in the planes (eta_bar, tau_d), (eta_bar, Delta), (eta_bar, J); Im lambda as first frequency; A4 also gives eta_bar_H). S3 runs M3 mean field and the N = 10^4 network (N = 5x10^4 for K8) at ref_ceni tau_d {3, 4.95, 8} ms and ref_devalle tau_d {5, 50} ms, 10 s. K7 to K9 block; K10 and K11 do not (a K10/K11 failure, or a K8 peak outside 25 to 100 Hz, triggers a units review and feeds G2 but does not block). K9 is judged as in Table 7.1: if its maximum differs from 0.1453, only the ratio scaling across eta_bar = 1, 2, 4 (agreement within +/- 0.002) blocks, and the maximum is reported. K4-net runs only once a source gives the M2 network coupling; until then it is recorded as not run. Sigma is calibrated from one N = 10^4 baseline at the P2 start state of ref_devalle (eta_bar_H - 1.5, J = -21, Delta = 0.3, tau_d = 5 ms), committed in a config, and frozen with the criteria at MS7 (D18, CP21, T04); 0.5 sigma and 2 sigma are the S11 levels. The headline cell (P2, ref_devalle, 120 s) is re-timed on the A4 path (T23). Any failure of a blocking check means the equations, the sign convention (C3) or the unit mapping is wrong; after two debugging rounds, stop new work (G0).
